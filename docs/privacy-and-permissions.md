# 隐私与权限说明

Universal Manga Translator 的主产品形态是纯 Chrome 插件。插件需要读取漫画页面里的图片，调用你配置的 OCR API 和 OpenAI-compatible 翻译 API，然后把译文覆盖渲染到当前网页。

## API Key 存在哪里

纯插件模式下，OCR API Key 和翻译 API Key 保存在浏览器扩展的 `chrome.storage.local` 中——只存在于本机浏览器配置文件，**不会**同步到 Google 账号、不会上传到云端、不会跨设备复制。项目作者不会接收、托管或中转你的 key。

普通偏好（目标语言、遮罩外观、站点开关等）保存在 `chrome.storage.sync` 中，会随你的 Google 账号在多设备间同步；其中不包含任何 API Key。

不要把带有个人 API Key 的浏览器配置文件、扩展数据目录或截图发给别人。提交 issue 时请不要粘贴完整 API Key，只保留前后几位用于区分即可，例如：

```text
key-a...last4
```

## 请求会发到哪里

插件会向这些位置发送请求：

- 你正在浏览的漫画网站：读取页面图片或截图。
- 你填写的 OCR API：上传漫画图片，用于识别文字和坐标。
- 你填写的 OpenAI-compatible 翻译 API：发送 OCR 得到的文本、上下文和术语表，用于生成译文。
- 可选本地 OCR HTTP 地址，例如 `http://127.0.0.1:9000/ocr`。

远程 OCR / 翻译 API 建议并要求使用 HTTPS；插件的直连代理只允许本机 loopback 地址使用 HTTP。这样可以避免 API Key 被明文发送到外网。

插件不会上传到项目作者服务器。本项目默认不提供云端代理服务。

## 为什么需要 `<all_urls>`

漫画网站域名很多，图片 CDN 也经常和页面域名不同。`<all_urls>` 让插件可以在用户启用过的网站中访问页面图片、跨域图片和你填写的 API 地址。

插件不会在所有网站默认运行。你需要先在 popup 中点击“启用此网站”，插件才会记住该主域名，并且只在类似漫画阅读页的页面上显示功能 UI。

## 为什么需要 `activeTab`

`activeTab` 用于当前标签页的交互，例如启用站点、注入内容脚本、框选翻译和截图 fallback。它只针对用户当前操作的标签页。

## 为什么需要 `storage`

`storage` 用于保存：

- 已启用的网站主域名。
- OCR API 和翻译 API 配置。
- 人名 / 术语表。
- 覆盖气泡显示参数。
- 缓存、手动编辑和删除状态。

## 不会收集什么

项目本身不会收集：

- 浏览历史。
- 账号密码。
- 支付信息。
- 完整 API Key。
- 非漫画页面内容。

实际 OCR 和翻译服务商会收到你发送给它们的图片和文本。请根据服务商自己的隐私政策判断是否适合使用。
