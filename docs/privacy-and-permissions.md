# 隐私与权限说明

Universal Manga Translator 的主产品形态是纯 Chrome 插件。插件需要读取漫画页面里的图片，调用你配置的 OCR API 和 OpenAI-compatible 翻译 API，然后把译文覆盖渲染到当前网页。

## API Key 存在哪里

纯插件模式下，OCR API Key 和翻译 API Key 只保存在本机的 `chrome.storage.local`，**不会写入 `chrome.storage.sync`**，因此不会随 Google 账号同步到其它设备，也不会经过 Chrome 同步服务器。项目作者不会接收、托管或中转你的 key。

其它设置（已启用域名、字段映射、气泡参数、术语表）保存在 `chrome.storage.sync`，方便多设备共享；这些字段里不含密钥。API 地址本身跟随偏好同步，密钥不跟随——换设备后需要重新填写 Key。

如果旧版本曾把密钥写进同步区，插件会在下次读取设置时自动把它们搬到本机存储，并把同步区里的那份副本清空（`directOcr.apiKeys` 置为空数组、`directTranslator.apiKey` 置为空字符串）。

不要把带有个人 API Key 的浏览器配置文件、扩展数据目录或截图发给别人。提交 issue 时请不要粘贴完整 API Key，只保留前后几位用于区分即可，例如：

```text
key-a...last4
```

## 请求会发到哪里

插件会向这些位置发送请求：

- 你正在浏览的漫画网站：读取页面图片或截图。
- 你填写的 OCR API：上传漫画图片，用于识别文字和坐标。
- 你填写的 OpenAI-compatible 翻译 API：发送 OCR 得到的文本、上下文和术语表，用于生成译文。
- 可选本地 OCR HTTP 地址，例如 `http://127.0.0.1:9000/ocr`。

远程 OCR / 翻译 API 建议并要求使用 HTTPS；插件的直连代理只允许本机 loopback 地址使用 HTTP。这样可以避免 API Key 被明文发送到外网。

插件不会上传到项目作者服务器。本项目默认不提供云端代理服务。

## 本地后端（可选高级用法）谁能访问

本地后端只监听 `127.0.0.1`，并且默认拒绝来自网页的请求：

- 请求的 `Origin` 必须是插件来源（`chrome-extension://…`）或本机 loopback 页面；其它网站页面一律返回 403，响应也不会带上 CORS 许可，所以网页既读不到也改不了后端。
- 每个非查询请求都必须带 `content-type: application/json`，网页表单这类“简单请求”无法直接驱动后端。
- `Host` 头必须是 loopback 地址，用来防止 DNS rebinding。
- 只有本机进程（桌面控制台、命令行工具）可以调用 `POST /v1/config` 修改 OCR / 翻译地址和 Key；浏览器上下文（包括插件自身）不行。桌面控制台因此把后端请求交给 Electron 主进程发出，网页壳自己不再直连。
- 事件流 `GET /v1/events` 需要先调用 `POST /v1/session` 领取一次性会话 id。WebSocket 不受 CORS 保护，没有会话 id 的握手会被拒绝，因此普通网页不能旁听你的翻译结果。
- 通过配置接口写入的 OCR / 翻译地址只允许 HTTPS，或本机 loopback 的 HTTP；明文 `http://` 指向外部主机时直接返回 400，避免 Key 和图片被明文发往公网。

已知残留风险：任何安装在你浏览器里的扩展都能以 `chrome-extension://…` 来源读取后端状态、提交任务或清理缓存（它们仍然不能改配置，也不能旁听事件流）。如果你不需要本地后端，请保持纯插件模式运行，不要启动 `apps/server`。

## 为什么需要 `<all_urls>`

漫画网站域名很多，图片 CDN 也经常和页面域名不同。`<all_urls>` 让插件可以在用户启用过的网站中访问页面图片、跨域图片和你填写的 API 地址。

插件不会在所有网站默认运行。你需要先在 popup 中点击“启用此网站”，插件才会记住该主域名，并且只在类似漫画阅读页的页面上显示功能 UI。

要收回授权，在同一处点击“停用此网站”即可：该域名会被删除，已经打开的页面会立刻取消队列中的翻译、关闭在途请求并清除覆盖层，不需要手动刷新。

## 为什么需要 `activeTab`

`activeTab` 用于当前标签页的交互，例如启用站点、注入内容脚本、框选翻译和截图 fallback。它只针对用户当前操作的标签页。

## 为什么需要 `storage`

`storage` 分两处使用：

- `chrome.storage.local`（只在本机）：OCR / 翻译 API Key、翻译缓存、手动编辑和删除状态。
- `chrome.storage.sync`（随账号同步）：已启用的网站主域名、OCR 字段映射与 API 地址、人名 / 术语表、覆盖气泡显示参数。

## 不会收集什么

项目本身不会收集：

- 浏览历史。
- 账号密码。
- 支付信息。
- 完整 API Key。
- 非漫画页面内容。

实际 OCR 和翻译服务商会收到你发送给它们的图片和文本。请根据服务商自己的隐私政策判断是否适合使用。
