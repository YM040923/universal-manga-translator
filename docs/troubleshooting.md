# 排错指南

先在 popup 里打开“API 设置 / 自检”。自检会暴露大多数配置问题，并且不会显示完整 API Key。

## OCR 失败：402 / 额度不足

含义：OCR 服务商账户没有额度，或当前 key 没有可用额度。

处理：

1. 换一个 OCR Key。
2. 给 OCR 服务商账户充值。
3. 降低“每次自动最大 OCR 页”，避免整章一次性消耗过快。

## OCR 失败：401 / 403 / Key 无效

含义：OCR Key 错误、过期，或账号没有访问该接口的权限。

处理：

1. 检查 OCR API Keys 是否多了空格。
2. 确认 OCR API URL 和 key 属于同一家服务商。
3. 在服务商控制台确认该 key 有 OCR 接口权限。

## OCR 失败：429 / QPS 受限

含义：请求过快。

处理：

1. 等一会儿再重试。
2. 降低并发或减少自动翻译页数。
3. 配置多个 OCR Key 轮换。

## fetch failed

含义：浏览器或网络层没有拿到响应。常见原因是 URL 填错、服务商网络不可达、本地 OCR 服务没启动、CORS 或证书问题。

处理：

1. 确认 OCR API URL 可以访问。
2. 如果是本地 OCR，确认 `http://127.0.0.1:9000/ocr` 这类服务正在运行。
3. 如果服务只支持 HTTPS，不要填写 HTTP。
4. 远程 OCR / 翻译 API 必须使用 `https://`；`http://` 只支持 `127.0.0.1`、`localhost`、`[::1]` 这类本机地址。
5. 如果服务商要求特殊字段，把它们填到 `staticFields JSON`。

## OCR 连通但未解析到文字区域

含义：接口返回了 JSON，但插件没有在配置路径里找到文字框。

处理：

1. 检查 `regionsPaths` 是否指向区域数组。
2. 检查 `textPaths` 是否指向文字字段。
3. 检查 `boxPaths` 是否指向坐标字段。
4. 参考 [api-templates.md](api-templates.md) 调整字段映射。

## 页面样本自检未返回

含义：popup 的 API 自检已连通 OCR，但没有从当前页面拿到真实漫画样本结果。

处理：

1. 确认当前标签页是漫画章节阅读页，不是目录页、首页或详情页。
2. 重载当前漫画页，再打开 popup 点自检。
3. 确认该网站已经点击过“启用此网站”。
4. 如果页面能正常翻译但自检仍不返回，请提交当前 URL、popup 自检文本和扩展日志。

## AI 返回非 JSON / Base URL 错误

含义：翻译 Base URL 不是 OpenAI-compatible API 地址，可能填成了网页地址。

处理：

1. Base URL 通常要以 `/v1` 结尾。
2. 自检会访问 `${Base URL}/models`。
3. 如果服务商没有 `/models`，确认它是否真的兼容 OpenAI 接口。

## 目录页也出现插件 UI

插件默认只在启用过的网站运行，并会判断是否像漫画阅读页。如果目录页、搜索页、首页误出现 UI：

1. 关闭“自动翻译本网站”。
2. 确认当前页面是不是章节页，而不是漫画详情页或目录页。
3. 记录页面 URL 和截图，提交 issue。

## 翻译气泡偏移

常见原因：

1. OCR 返回的坐标不是原图坐标，而是缩放后的坐标。
2. 漫画网站在图片加载后又改变了布局。
3. 图片被浏览器延迟加载，首次扫描时尺寸不稳定。

处理：

1. 刷新页面后等待图片加载完成再翻译。
2. 确认 OCR 服务返回原图坐标系。
3. 尝试清除覆盖后重新翻译当前页。

## 翻译结果不自然

处理：

1. 在“人名 / 术语表”里固定人名、地名、组织名和招式名。
2. 对不满意的页面点“重翻本页”。
3. 手动编辑气泡文字；删空气泡文字会移除该气泡并保存删除状态。
