# Release 0.2.0

相比 0.1.x 的大版本更新：翻译体验、覆盖层质量、安全与工程可靠性的系统性修复。

## 翻译

- **中文语序与短句化**：重写翻译指令，强制按中文语序重排、长句拆短句、去除翻译腔（被字句/的字堆叠/填充词）。
- **武侠模式**：popup → API 设置 → 翻译风格 可选"武侠"；武侠/武林漫使用专用规则（门派、功法、境界、绰号按中文武侠惯例译，战斗台词短促有力）。
- **分批 + 上下文延续**：单次请求最多 12 条，且后面的批次自动携带本页前文译文，整页翻译的人名/语气/语序保持一致。
- **漏字修复**：模型漏掉的条目回退显示原文，不再凭空消失；请求加 `max_tokens` 上限，长页输出不再被截断。
- **术语表/人名候选**：自动提取的人名候选收紧去噪，术语表版本纳入缓存键。

## 覆盖层

- **气泡合并收紧**：相邻的独立气泡不再被融合成一个巨型覆盖块；同一气泡内被 OCR 拆开的行仍会合并。
- **拟声词不遮挡**：韩文、纯标点、无法识别的短非拉丁文本判为拟声词，使用透明底 + 白描边，不再出现白底块（含页面级语言判定，不影响日文/中文原版正文）。
- **框选翻译锚定**：结果按选区下方真实内容元素定位，滚动/布局变化不再错位。
- **换行**：中英混合文本强制分行、行数上限提升、字号估算更保守，长句不再溢出被裁。
- **调试覆盖层**：开启后直接在区域框内显示 OCR 原文（白字）与译文（黄字），便于判断是 OCR 读错还是翻译问题。

## 支持与可靠性

- **iframe 阅读器**：内嵌框架（含跨域 reader）内的漫画可检测和翻译。
- **抓图兜底**：图片 CDN 拒绝直连时，视口内图片自动改用截图裁剪 OCR。
- **取消即中止**：取消翻译会中止在途 OCR/翻译请求，不再为已取消的工作计费。
- **API Key 本机存储**：密钥存入 `chrome.storage.local`，不随 Google 账号同步；旧版配置自动兼容迁移。

## 后端（高级模式）

- 安全加固：仅接受扩展/本机来源（CORS 白名单 + Host 校验 + WebSocket Origin 校验）、SSRF 防护、请求限流、并发限制、在途去重、单面取消、缓存 LRU 与过期清理、日志轮转。
- 取消会话真正中止在途调用（AbortSignal 贯穿 OCR/翻译/抓图）。

## 工程

- CI 修复：GitHub Actions 的 Windows PowerShell 受限语言模式问题已解决（改用 pwsh），`typecheck / test / e2e / 打包` 全绿。
- 发布校验：构建失败不再静默打包旧产物；发布包会比对 zip 内 manifest 版本。
- 测试修复：中文断言乱码的测试文件已转 UTF-8；新增合并、SFX、锚定、分批上下文等回归测试。
- 桌面端：模型名注入转义、沙箱开启、清理端口前先确认为本后端。

## 已知限制

- 气泡轮廓识别仍基于 OCR 文本框 + 几何启发式（非视觉模型），重叠/斜向/贴边气泡可能不准。
- 阅读页判定依赖 URL 与图片几何特征，个别站点可能需要手动框选。
